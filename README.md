# Dark Mithril

The VS Code dark theme with blue-grays and gold (amber) accents and highlights. The palette is inspired by the [Mithril gold-trimmed armour](https://oldschool.runescape.wiki/w/Mithril_gold-trimmed_set_(lg)) from Old School RuneScape.

## Install

```bash
code --install-extension dark-mithril-theme-0.0.10.vsix
```

Then run *Preferences: Color Theme* and choose **Dark Mithril**.
